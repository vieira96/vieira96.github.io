# Samuel Vieira da Silva de Oliveira — Portfólio

Este é o portfólio de Samuel Vieira da Silva de Oliveira. Trabalho com desenvolvimento web desde 2021, principalmente com PHP e Laravel no backend e JavaScript e TypeScript no frontend.

**Site:** https://vieira96.github.io/portfolio/

![Prévia visual do portfólio](assets/portfolio-preview.png)

## Perfil

- No trabalho, desenvolvo e mantenho sistemas web e APIs com PHP/Laravel.
- No frontend, trabalho com JavaScript, TypeScript, Vue.js, Nuxt.js, React.js e Next.js.
- Nos projetos pessoais, desenvolvo APIs e serviços com Node.js, Express e NestJS.
- Estou aberto a oportunidades remotas Backend ou Full Stack.

## Tecnologias do site

HTML, CSS, JavaScript, Tailwind CSS compilado, Google Fonts e Material Symbols.

Os projetos são mantidos em [`projects.json`](projects.json) e renderizados como HTML estático durante o build, para que seu conteúdo seja visível a buscadores e leitores sem JavaScript.

## Desenvolvimento local

```bash
npm install
npm run build
npm run dev
```

Depois, abra `http://localhost:8000`.

## Publicação

O projeto é estático e pode ser publicado diretamente no GitHub Pages. Antes de enviar alterações, execute `npm run build` para atualizar os cards de projetos e o CSS compilado.
